Install

KAT Comment Studio is not on the VS Code Marketplace. It ships as a VSIX committed to the repository, so installing it is a three-step manual step.

Install from VSIX

  1. Download the latest release.
  2. Press Ctrl+Shift+P, type VSIX, and choose Extensions: Install from VSIX…
  3. Browse to the downloaded kat-comment-studio-1.0.12.vsix and select it.

You can also install from a terminal:

code --install-extension kat-comment-studio-1.0.12.vsix

Updating

Installing a newer VSIX over an older one replaces it. There is no automatic update check — re-download when a new version is published.

After installing

Nothing needs configuring. Rendering, anchor scanning, prefix highlighting, and issue links are all on by default. If you want to change that, start with the Settings Reference.

First run. The workspace is scanned for anchors on activation, and the status bar shows a highlighted N Anchors badge until you open the Code Anchors panel for the first time. Both behaviors are configurable — see scanOnLoad and showAnchorCountBadges.
