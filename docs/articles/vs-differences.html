VS vs VS Code

This extension is a port of madskristensen/CommentsVS for Visual Studio 2022. Some things the VS extension does are impossible or unwise in VS Code; this page records what changed and why.

Implemented differently

Visual StudioVS Code port
WPF inline adornment replacing the comment with styled controls CodeLens plus a hover popup. The VS Code decoration API cannot replace text with arbitrary rendered content.
Off / Compact / Full rendering modes A single on mode — CodeLens, hover, auto-fold. A compact inline summary is not achievable through the extension API.
Double-click a rendered comment to edit the raw source Not available; decorations do not receive click events. Auto-unfold when the caret enters is used instead.
Auto-reflow while typing Reflow on caret exit from the block. Per-keystroke reflow would fight the undo stack. See auto-reflow.
Format Document integration (Ctrl+K, Ctrl+D) No formatting provider is registered — it would conflict with C# Dev Kit and OmniSharp. Use Reflow Comments in File.
Background parallel solution scanning A synchronous scan with a progress notification. Fast enough for typical workspaces.

Not implemented

Visual Studio featureWhy not
Left border indicator on rendered commentsNo persistent left-border gutter marker exists in the decoration API.
Comment Remover — 7 specialized commandsReduced to two: Remove Current and Remove All.
Export to TSVCSV, Markdown and JSON are supported; TSV is a spreadsheet save-as away.
“Use Compact Style for Short Summaries”There is only one rendering mode.
“Preserve Blank Lines”Blank lines between XML elements are normalized during reflow for consistency.

Added in the VS Code port

  • LINK: navigation — hover previews, path completion, go-to-definition, and diagnostics for broken targets.
  • JSDoc / TSDoc rendering for JavaScript and TypeScript.
  • Markdown anchor scanning, where every line is prose.
  • A sortable, resizable grid panel with scope, search and type filters shared with the tree.
  • .editorconfig support for reflow line width.
