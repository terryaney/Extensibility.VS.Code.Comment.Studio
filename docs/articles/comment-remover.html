Comment Remover

Deletes documentation comment blocks — one at the caret, or every block in the file. Useful when you inherit a file full of auto-generated stub comments.

Commands

CommandWhat it removesWhen it is enabled
Remove Current XML Comment The doc comment block containing the caret. Only when the caret is inside a doc comment.
Remove All XML Comments in File Every doc comment block in the active file. Always.

Both are on the editor context menu under KAT Comment Studio, and in the command palette.

What counts as a doc comment

Despite the command names, this is not XML-only. Any block written in the current language's documentation style is removed:

StyleLanguages
///C#, F#, C/C++, Razor
'''VB
/** */TypeScript, JavaScript, TSX, JSX
##, <# #>PowerShell
---SQL
(** *)F# block form
Ordinary comments are safe. A plain //, # or ' comment is recognized but never deleted by these commands — only documentation blocks are.
Removal is a single edit. Both commands apply as one editor edit, so Ctrl+Z restores everything they removed in one step. There is no confirmation prompt.
