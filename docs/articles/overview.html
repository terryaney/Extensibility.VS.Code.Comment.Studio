KAT Comment Studio

A VS Code extension that turns raw XML doc comments and JSDoc blocks into clean inline summaries, and tracks TODO-style anchors, issue references, and cross-file links across your whole workspace.

Topics

  • XML Doc RenderingFold XML doc blocks into a one-line CodeLens with a formatted popup.
  • JSDoc / TSDocThe same rendering for /** */ blocks in JS and TS.
  • Comment ReflowWrap and normalize doc comments on exit, paste, or on demand.
  • Code AnchorsTODO, HACK, BUG and custom tags tracked across the workspace.
  • Prefix HighlightingBetter Comments-style coloring for !, ?, *, //, -, >.
  • LINK: NavigationCross-file references with hover, completion, and Ctrl+Click.
  • Issue LinksTurn #123 into a link to your tracker.
  • Comment RemoverStrip one doc comment block, or all of them.
  • Settings ReferenceEvery setting, its type, and its default.
  • ColorsTheme color IDs and colorOverrides keys.
  • Commands & KeysPalette entries, F1 interception, suggested keybindings.
  • EditorConfigPer-project reflow line width.

Two kinds of feature

Knowing which group a feature belongs to explains where it works.

GroupFeaturesWhere it works
Doc comment CodeLens summary, documentation popup, auto-fold, opacity, reflow, comment remover Only in languages with a known doc-comment style — see the table below.
Comment text Code anchors, prefix highlighting, issue links, LINK: navigation Every file you open. These read comment text with a language-agnostic scanner, so they work in JSON, YAML, shell scripts, and anything else.

Supported languages

This table applies to the doc comment group only.

LanguageDoc comment styleCodeLens & popupReflow
C#///✓✓
VB'''✓✓
F#///✓✓
C / C++///✓✓
Razor / cshtml///✓✓
TypeScript / TSX/** */✓—
JavaScript / JSX/** */✓—
SQL---——
PowerShell##, <# #>——
Why some rows say “—”. JSDoc languages are not reflowed because rewrapping would corrupt @tag lines. SQL and PowerShell are parsed as doc comments — Comment Remover handles them — but CodeLens is deliberately suppressed for both.
Anchors are not limited to this list. Code anchors, prefix highlighting, issue links, and LINK: work in any file. Markdown gets special handling: because the whole document is prose, every line is scanned rather than only comment lines. See Markdown and prose files.
