Commands & Keys

Every command lives under the KAT Comment Studio category in the command palette (Ctrl+Shift+P). Only F1 is bound out of the box.

Commands

CommandDoes
Toggle Comment RenderingTurn rendering on or off
Reflow Current CommentReflow the block containing the caret
Reflow Comments in FileReflow every block in the document
Show Comment TooltipShow the rendered documentation popup. Enabled when the caret is in or just below a doc comment. Also on F1.
Scan Code AnchorsRescan the workspace, with a progress notification
Export Code AnchorsExport visible anchors as CSV, Markdown or JSON
Set Anchor ScopeChoose Workspace / Folder / Document / Open Docs / Repo / Project
Filter Anchor TypesShow or hide individual anchor types
Go to Next AnchorJump to the next anchor in the file
Go to Previous AnchorJump to the previous anchor in the file
Remove Current XML CommentRemove the doc comment block at the caret
Remove All XML Comments in FileRemove every doc comment block in the file

VS Code also generates these — search for them by name:

  • View: Toggle KAT Comment Studio / View: Show KAT Comment Studio — show or hide the sidebar
  • Focus on KAT Comment Studio - Code Anchors View — focus the grid panel

F1 interception

With interceptF1ForComments at its default of true, pressing F1 runs Show Comment Tooltip when the caret is inside an XML doc comment block, or on the first non-blank code line directly below one — typically the method signature.

Everywhere else F1 still opens the normal VS Code help menu. Set interceptF1ForComments to false to disable the interception entirely.

Keyboard shortcuts

No shortcuts other than F1 are registered. To bind one, open File → Preferences → Keyboard Shortcuts (Ctrl+K Ctrl+S) and search for KAT Comment Studio.

Two worth binding:

Suggested keyCommand ID
Alt+PageDownkat-comment-studio.nextAnchor
Alt+PageUpkat-comment-studio.previousAnchor

Menus

Rendering toggle, both reflow commands and both remover commands are also on the editor context menu, under a KAT Comment Studio submenu.
