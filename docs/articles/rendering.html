XML Doc Rendering

Collapses an XML documentation block down to a single readable CodeLens line, so a well-documented file stays skimmable. Click the summary to see the full comment formatted as a popup.

A raw XML doc comment costs a lot of vertical space and is hard to read — inconsistent blank lines, an element break mid-sentence, one very long line, and an unrendered code block:

With rendering on, the whole block folds to one line:

What rendering does

  1. The block collapses. At xmlCommentOpacity: 0 it is fully transparent — only the fold chevron, the … decoration, and a single line height remain, so you can still click into it and edit.
  2. It auto-unfolds when the caret enters, and re-folds shortly after the caret leaves. Both delays are configurable — see timing.
  3. A CodeLens shows the <summary> text above the member. Long summaries truncate at codeLensSummaryTruncation (default 205 characters; 0 disables truncation). When the summary has multiple <para> elements, only the first is shown.
  4. Clicking the CodeLens opens the documentation popup.

Documentation popup

Click the summary text in a CodeLens, or press F1 with the caret in or directly below the comment (see F1 interception).

The popup always shows the full content — codeLensSummaryTruncation only affects the CodeLens line. Sections rendered:

SectionRendering
SummaryStyled text
ParametersName and description
ReturnsInline with the description
RemarksLabel on its own line, content indented below
ValueProperty value description
ExampleFenced code block
ExceptionsList of exception types and descriptions
See AlsoClickable links
Anchor tagsTODO:, NOTE:, HACK: and friends, colored by anchor type

Inline formatting is rendered too: code, bold, italic, strikethrough, and hyperlinks.

Supported XML tags

<summary>, <param>, <typeparam>, <returns>, <value>, <remarks>, <example>, <exception>, <see>, <seealso>, <inheritdoc>, <paramref>, <typeparamref>, <c>, <code>, <list>

Turning rendering on and off

WhereHow
Command paletteKAT Comment Studio: Toggle Comment Rendering
Editor context menuKAT Comment Studio submenu
Status bar OFF / ON — click to toggle

The persistent default is the xmlCommentRendering setting.

Collapse when rendering is off

Set collapseXmlWhenRenderingOff to true to fold every XML doc block as a file opens. It only applies while rendering is off — when rendering is on, blocks are folded anyway.

Related settings

xmlCommentRendering, xmlCommentOpacity, codeLensSummaryTruncation, collapseXmlWhenRenderingOff, interceptF1ForComments — all documented in the Settings Reference.
