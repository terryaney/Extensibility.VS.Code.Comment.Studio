JSDoc / TSDoc

TypeScript, JavaScript, TSX and JSX /** */ blocks get the same CodeLens summary and documentation popup as XML doc comments. Doxygen-style \tag syntax is recognized too.

The CodeLens summary comes from the free text before the first @tag. Clicking it opens the popup.

No reflow for JSDoc. Comment reflow is deliberately not applied to /** */ blocks — rewrapping would break @tag lines.

Tag mapping

TagPopup section
free text before any tag, @description, @summarySummary
@param, @arg, @argumentParameters — with type, if {type} is given
@returns, @returnReturns — with type and description
@throws, @throw, @exceptionExceptions — exception type as the heading
@exampleExample — fenced code block
@remarks, @noteRemarks
@see, @seealsoSee Also
@deprecatedDeprecated, under Other
@typeparam, @templateType Parameters
@typeType annotation prepended to Summary
@briefSummary — Doxygen; used only when there is no free-text description
anything elseOther, with @tagname as the heading

Parameter forms

@param {string} name              plain
@param {string} [name]            optional
@param {string} [name=default]    optional with default
@param {...number} rest           rest parameter
@param {Object} options
@param {string} options.sub       dotted name

The {type} brace expression handles nested generics such as Object.<string, Array<T>>.

Example

/**
 * Resolves a user by primary key.
 *
 * @param {string} id   The user identifier.
 * @param {Object} [options]
 * @param {boolean} [options.includeDeleted=false]
 * @returns {Promise<User|null>} The user, or null when not found.
 * @throws {ArgumentError} When id is empty.
 * @example
 * const user = await getUser('42');
 */
